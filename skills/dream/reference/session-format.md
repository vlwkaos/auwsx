# Session Format Reference

```yaml
---
title: Session description
target_slugs: [auth-flow, jwt-validation]
kind: domain
created: 2026-04-01T10:00:00
---
## auth-flow
Content → knowledge/domain/auth-flow.md

## jwt-validation
Content → knowledge/coding/jwt-validation.md
```

Multiple slugs from multiple sessions are merged. Session `kind` sets subdirectory.
