## form-cursor-editing

- Added a `cursor` character index to `FormField`, initialized at the end of each field value.
- Added UTF-8-safe insert, backspace, delete, left, right, home, and end behavior for active form fields.
- Updated repo path completion to replace the field value through `set_value`, keeping the cursor at the suggestion end.
- Updated form rendering to draw `_` at the stored cursor position instead of always appending it.
- Added focused tests for middle insertion, backspace, delete, stale UTF-8 cursor clamping, repo completion cursor placement, and rendered cursor position.
