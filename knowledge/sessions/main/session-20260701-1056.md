## remote-workflow-queueing

- Added `remote_workflow` as the daemon-owned bridge from pure `remote_plan` decisions to queued `remote_sync_runs`.
- Added duplicate active-run guard for project/issue/kind so repeated scheduler or merge commands do not enqueue duplicate outbound work.
- Scheduler now queues remote issue sync when approved backlog routing creates a local issue and outbound issue creation is enabled.
- PR merge mode now routes issue merge and project merge approvals into PR sync queueing instead of local `MERGING`.
- Project PR merge still leaves issues `READY_TO_MERGE`; a future remote executor must update remote links and final local status after provider actions complete.
- Tests cover backlog promotion to remote issue sync, per-issue PR merge queueing, and multi-ready project PR queueing.
