## path-dep-stability

The dependency is `wsx-core = { path = "../wsx/crates/wsx-core" }` declared in `/Users/vlwkaos/ws/auwsx/Cargo.toml` (root workspace.dependencies) and re-referenced as `{ workspace = true }` in `/Users/vlwkaos/ws/auwsx/crates/auwsx-core/Cargo.toml`. Because the crates layout now lives on wsx main, **any checkout of wsx — main, feature branches, or worktrees** — will satisfy the path dep as long as the wsx repo continues to use the workspace structure. The earlier branch-coupling footgun (where checking out wsx main reverted the layout) is gone.

This also means: NO publishing to crates.io needed. NO git URL dep. The dependency is purely local and updates instantly when wsx-core source changes. Lockfile in auwsx pins exact transitive deps; wsx-core itself is "tracked by path" not "tracked by version" — cargo recompiles on every change to its sources.

If wsx ever moves repo location, BOTH of these need updating in lockstep:
- `/Users/vlwkaos/ws/auwsx/Cargo.toml` line 63
- `/Users/vlwkaos/ws/auwsx/crates/auwsx-core/Cargo.toml` line 34
