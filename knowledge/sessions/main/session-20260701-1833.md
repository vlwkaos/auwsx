## tui-remove-issue-selection-index

- Removed `App::issue_sel` after deleting the fullscreen Issue view.
- Issue selection now comes only from focused issue detail, selected kanban issue, or selected tree issue row.
- `selected_active_issue_id` delegates to `selected_issue()` and filters terminal issues.
- Removed stale update/clamp paths that mirrored tree selection into a hidden issue index.
