## tui-project-detail-focus-layer

- Added `Focus::ProjectDetail` and `ProjectDetailSection` for Recovery, Remote, Kanban, Preview, and Archive.
- Enter on a project row now focuses the right-side project detail pane instead of jumping straight into kanban.
- j/k and h/l move the selected right-side project section; Enter activates the selected section.
- Enter on Kanban or Preview focuses the kanban cards; Esc returns kanban -> project detail -> left tree.
- Footer hints now model project-detail context through `FooterContext::ProjectDetail`.
- Project detail rendering highlights the selected right-side section while keeping kanban card focus separate.
