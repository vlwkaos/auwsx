## auwsx-remote-repo-interface-slice

- Added per-project remote repository model: `project_remote_configs`, `remote_issue_links`, `remote_pr_links`, `remote_events`, and `remote_sync_runs`.
- Added typed DB CRUD in `crates/auwsx-core/src/db/remote.rs` plus IPC/CLI commands:
  - `auwsx project remote get <project_id>`
  - `auwsx project remote set <project_id> ...`
  - `auwsx project remote delete <project_id>`
  - `auwsx project remote sync-runs <project_id>`
  - `auwsx project remote plan <issue_id>`
- Added TUI project-level `R remote` popup for URL, owner/repo, API base URL, auth refs, webhook secret ref, inbound `/auwsx-run`, outbound remote issue creation, PR merge, comment sync, draft PR, checks policy, labels, assignees, and PR base branch.
- Added `crates/auwsx-core/src/remote_plan.rs` as a pure model planner. It produces deterministic actions for remote issue creation, PR create/update, progress comments, and inbound `/auwsx-run` backlog acceptance without calling GitHub or SQLite.
- Verification passed:
  - `cargo fmt --package auwsx-core --package auwsx-tui`
  - `cargo test --package auwsx-core -- --test-threads=1`
  - `cargo test --package auwsx-tui`
  - `cargo build --workspace`
  - `cargo test --package auwsx-core --package auwsx-tui --no-run`
  - `rg -n 'Color::' crates/auwsx-tui/src/ui/ -g '!theme.rs'` returned no matches.
  - User-path grep over changed remote/TUI files returned no matches.
