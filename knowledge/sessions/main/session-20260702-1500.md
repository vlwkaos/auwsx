## tui-enter-vs-collapse-expand

- Changed overview tree semantics so `Enter` opens detail contexts only.
- `h`/left collapses the highlighted project or archive root.
- `l`/right expands the highlighted project or archive root.
- Archive/project section roots no longer advertise `Enter` fold/open hints.
- README key help and TUI footer now document `h/l` for collapse/expand.
