## project-config-and-scheduling

### Schedule cadence rule (the user's core confusion — was misdocumented)
`projects.schedule_interval_min` (verified `scheduler.rs:181-190` `project_due_for_auto_tick`):
- **NULL** → NEVER auto-tick (truly manual; only explicit `RunSchedulerOnce` IPC runs it). This is the DB default → every new project was born manual-only.
- **`<= 0`** → tick on EVERY global daemon loop.
- **`n > 0`** → due when `now - last_auto_tick.fired_at >= n*60_000`.
- Global loop cadence = `AUWSX_TICK_SECS` env, **default 10s**, `.max(1)` floor (`cli.rs:423-427`). So `0` = evaluated every 10 seconds.
- CRITICAL distinction: a tick only EVALUATES; it spawns an agent only when there's actionable work AND `max_concurrency` has a free slot. Idle ticks are cheap no-ops. So `0` is "react within 10s", not "spawn constantly".
- CORRECTION of an earlier wrong claim this session: "manual" does NOT mean "default behavior" — it means literally never auto-tick.

### Full projects-table config reference (verified vs 0001_init.sql + pipeline/scheduler/state)
Grouped; defaults from migration `0001_init.sql`:
- **Identity**: name, repo_path, default_branch(`main`).
- **Agent cmds** (which AI per role): main_agent_cmd, plan_agent_cmd, work_agent_cmd, review_agent_cmd (NULL→falls back to work_agent_cmd). `{prompt}` substituted at spawn.
- **Scheduling**: schedule_interval_min (see above).
- **Soft gates** (issue pauses, timer arms, auto-advances if no human acts):
  - `plan_gate_timeout_min`(10) gates PLANNED→IMPLEMENTING; `0`=immediate.
  - `completion_policy`(manual) gates ENDED→COMPLETING: manual=wait forever; soft=wait `completion_soft_timeout_min`(60) then auto-merge; auto=merge immediately.
- **Hard timeouts / caps** (runaway protection):
  - `iteration_timeout_min`(30): per-phase agent hard timeout → kill → issue FAILED (`pipeline.rs:178`).
  - `main_job_timeout_min`(60): same for main-queue jobs/routines (`main_job_runner.rs:95`).
  - `review_max_rounds`(5): REVIEW↔NEEDS_FIX cycles before forced AUDIT.
  - `conflict_max_attempts`(3): merge-conflict retries before parking at CONFLICT_BLOCKED.
- **Concurrency/integration**: `max_concurrency`(1) = concurrent issues per project (`scheduler.rs:59-70` `slots = cap - running.len()`); `merge_mode`(local) = rebase+`--no-ff` merge vs `pr` = open PR.
- **Skills/maintenance**: skill_path (NULL=global default), deepsleep_interval_days(7) + last_deepsleep_at.
- **Autonomous-operation recipe**: `schedule_interval_min=0` + `completion_policy=auto` + `plan_gate_timeout_min=0` + approved backlog. Otherwise issues park at PLANNED/ENDED waiting for a human.

### DB location (macOS) + how to edit when daemon is down
- State DB resolves via `directories::ProjectDirs` → on macOS that's **`~/Library/Application Support/auwsx/state.db`** (NOT `~/.local/share` — that's only the non-macOS fallback in `db/mod.rs:128-137`). Override: `AUWSX_DB_PATH`.
- Writes are daemon-owned by design, but there is NO `project update` CLI verb. When the daemon is down (single writer, no race), a direct `sqlite3` UPDATE is the only path. Set auwsx project: `UPDATE projects SET schedule_interval_min = 0 WHERE id = 1;`. Daemon reads it on next start.

## Trials & Solutions
- Subagent ran `cargo build` (skips test code) and reported clean, but `NewProject`/`AddProject` are constructed in `crates/auwsx-core/tests/` (crud/agent/ipc/autonomy) — 20 sites broke with E0063. Lesson: after a struct/enum-variant signature change, verify with `cargo test --no-run` (or `cargo test`), NOT `cargo build`, because build skips test targets. Fixed all 20 with `schedule_interval_min: None`.
- COALESCE bind-order risk: new `schedule_interval_min = COALESCE(?, ...)` SET column must have its `.bind()` in matching positional order, before `.bind(id)` (WHERE). Verified correct.
- Tree label `⏱every tick next every tick` redundancy: interval_label and tree_countdown both return "every tick" for Some(<=0). Fixed in tree_rows: when countdown == interval, show just `⏱{interval}`.
- macOS DB path: first looked at `~/.local/share/auwsx/state.db` (the docstring's non-mac fallback) and found nothing; real path is `~/Library/Application Support/auwsx/` via ProjectDirs. `pgrep`/sysmon is sandbox-blocked here; use `ps aux | rg` with sandbox off to check the daemon.
- delegate-sonnet-mode is ON for this session (Opus plans/reviews; Sonnet subagents implement). Mid-session memory-file edits don't enter the loaded instruction set, so adherence is manual within a session.
