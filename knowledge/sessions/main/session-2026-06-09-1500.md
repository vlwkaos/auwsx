## typed-db-crud-conventions

- **Clock injected**: every stamping CRUD fn takes `now: i64` (epoch ms). Keeps CRUD deterministic/unit-testable; the daemon (`ipc::now_ms`) is the single clock owner and supplies real time per request. Do NOT call `SystemTime` inside CRUD.
- **Enum ↔ SQL**: hand-rolled `as_str`/`from_str` (mirroring `IssueStatus`) is the SQL-bind path; `#[serde(rename_all="snake_case")]` is the JSON/IPC path. Both must agree (they do). New pairs this session: `MergeMode`, `CompletionPolicy`, `Severity`, `FindingStatus`, `agent_runs::Role`, `agent::ExitKind` — all added to `coding/good-to-go-axes.md` parity table.
- **Row decode**: per-struct `from_row(&SqliteRow) -> Result<Self>`, `try_get` each col, parse enum strings with `from_str().ok_or_else(..)`. No `FromRow` derive (enum cols need custom parse).
- **Mutators return Err on missing id** (rows_affected==0 → not-found), so callers can distinguish.
- **issues**: `transition()` enforces `state::check_transition`; `force_status()` is the human-override bypass (logged by caller). `mark_absorbed` = CONSOLIDATING→ABSORBED + target id.
- **steering::add** is transactional: append note + set `has_pending_steering=1` together; guarded by `IssueStatus::accepts_steering` (working phases only).
- **backlog::run_triage** (v1, no grouping): promote each Approved + ungrouped item into its own CONSOLIDATING issue, set `consumed_issue_id`.
- **agent_runs**: append-only, two-step (`start` at spawn / `finish` at exit); `issue_id`/`main_job_id` xor enforced in code.

## ipc-response-adjacent-tagging

**Gotcha (cost a debug cycle, caught by blind test writer):** an enum used as a JSON-lines wire reply with newtype variants wrapping a primitive / sequence / option CANNOT use serde **internal** tagging (`#[serde(tag="kind")]`) — `serde_json` errors "cannot serialize tagged newtype variant … containing an integer/sequence". It silently works for unit + struct variants, so in-process tests pass and only the socket path fails. Fix: **adjacent** tagging `#[serde(tag="kind", content="data")]` — payload goes in its own `data` field, every variant shape round-trips. `Response` (has `Id(i64)`, `Projects(Vec<_>)`, `Project(Option<_>)`) needs this; `Command` (all unit/struct variants) is fine with internal tagging. See doc comment on `ipc::Response`.

- **Transport**: `serve(db, events, &socket, shutdown: Arc<Notify>)` — JSON-lines over `UnixListener`, per-conn task, removes stale socket on bind + on exit. `Shutdown` cmd or SIGINT → `Notify`. `request(&socket, &cmd)` one-shot. `EventStream::connect` drains the Ok ack then yields `Event`s. Socket path: `$AUWSX_SOCK` > `$XDG_RUNTIME_DIR/auwsx.sock` > cache dir > `$TMPDIR`.
- **dispatch is pure** (`db`, `events`, `now`, `cmd` → `Response`) → unit-tested without a socket; transport tested separately.

## agent-subprocess-runner

- **No tmux, no trait.** `agent::run(AgentSpec) -> Result<AgentOutcome>` spawns the agent CLI as a direct `tokio::process` child auwsx owns. The old `AgentRunner` trait + 3 impls + `AgentHandle`/`SignalDone`/tmux are GONE.
- **No shell**: `build_argv(template, prompt)` splits the template on whitespace; tokens containing `{prompt}` get the substring replaced (prompt stays ONE arg even with spaces). If NO `{prompt}` token → prompt is fed to child stdin (the `opencode` shape). So prompt content can never inject args. Tradeoff: templates can't use pipes/quotes — plain flag list + `{prompt}`.
- **Capture**: combined stdout+stderr → `log_path` (truncate). **Timeout**: `tokio::time::timeout` on `child.wait()`; on expiry `start_kill()` + reap → `ExitKind::Timeout`. `kill_on_drop(true)`.
- **Classification**: exit code present → `Exited`; signaled (code None) → `Killed`; spawn failure (bad binary) → returns `Ok(AgentOutcome{Error,..})` (not Err) + writes failure note to log; only log-file setup I/O failures propagate as `Err`.
- `{claude,codex,opencode}.rs` reduced to `NAME` + `DEFAULT_CMD` template constants (claude/codex use `{prompt}`; opencode uses stdin).

## Trials & Solutions
- Tried `Response` with internal serde tagging (`tag="kind"`) → blind test writer's transport test failed: `serde_json` can't serialize `Id(i64)` (and would also fail `Vec`/`Option` newtype variants) under internal tag; in-process dispatch tests passed (no serialization) masking it → switched to adjacent tagging (`tag="kind", content="data"`); added doc comment as the discoverable hint.
- Tried a generic `update_one` HRTB-closure helper in `issues.rs` to dedupe UPDATEs → sqlx `'q` lifetime vs captured `Option<&str>` args fought the `for<'q>` bound → inlined each UPDATE with a shared `ensure_found(rows_affected, id)` instead.
- No clap (project "stay light") → hand-rolled `Parsed` arg splitter (positionals + `--k v`/`--k=v` + bool flags); kept `parse` pure so 48 grammar tests need no socket.
