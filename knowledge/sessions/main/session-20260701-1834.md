## tui-remove-fullscreen-issue-view

- Removed `View::Issue` and its fullscreen renderer branches.
- Kept `ui/issue.rs` as the shared issue-detail log renderer used by the Overview right pane.
- Deleted the unused `PhaseNote` projection model; concise phase reports now flow through `issue_summary_rows`.
- Reordered Overview issue summary lines so phase report rows render before branch/worktree metadata in the fixed-height Summary panel.
